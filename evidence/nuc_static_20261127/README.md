## 已修复的退出崩溃

[修复前 GDB 调用栈](driver_shutdown_gdb.txt) 显示：SDK 内的 `std::shared_ptr<spdlog::logger>` 析构调用了系统 `libspdlog.so.1.12` 的 `_M_dispose` 并 SIGSEGV。SDK 自带 spdlog **1.3.1**，两版本的 C++ 符号在同一进程中发生抢占。

Linux 共享库新增 `sdk_core/exports.map`，只导出头文件声明的 62 个 C API，隔离 SDK 内部 spdlog/fmt/C++ 符号；不修改系统 ROS 日志库。`tools/check_livox_exports.py` 对实际 ELF 动态符号表检查 API 完整性和内部符号泄漏，并纳入驱动构建入口。NUC 编译和符号检查通过；第二轮实机清理驱动返回 0，见 [退出日志](after_sdk_fix/driver_exit.txt)。
