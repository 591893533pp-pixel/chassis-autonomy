# 立柱独立PV验证

入口：`python3 reports/20260924_lift/lift_pv_remote.py --hardware`（在workspace运行）。这不是原整机联合示例，不发送四轮控制帧。共用原遥控进程锁，不得与其他CAN控制程序同时运行。

启动只回读并等待手柄。全部松开后按START，立柱才切PV模式3并使能；X上、Y下，松开写60FF=0、保持使能。双扳机停止并退出；Ctrl+C也退出。每次长按最多2秒，必须松开才能重新运动；同时X/Y、直接换向或其他运动输入均阻止继续运动。正常停止读回速度绝对值≤10 counts/s且仍OperationEnabled才记录zero_verified。

当前请求速度±2 mm/s，对应整数目标±233 counts/s，换算800×7/48=116.6667 counts/mm，约1.997143mm/s。保留绝对0–250mm边界检查，方向限位提前1mm；测试相对启动位置±7mm提前阻止向外运动，±8mm触发退出。这些是软件保护，并非机械制动保证。首次只做Y短按1秒→松开→再Y短按1秒→松开。

100ms SDO超时，手柄读线程心跳150ms上限，主循环超时300ms退出；手柄设备断开退出。Linux手柄缓存并不能独立证明无线链路始终健康，因此另设2秒长按硬性软件限时；物理急停仍需可用。反馈失能、模式变化、反馈速度>500counts/s或零速命令后0.5s仍未停均退出，无自动故障复位/重新使能。

退出依次尝试零速→150ms→失能→NMT pre-op，记录独立步骤是否成功及最终位置/速度/状态。不自动恢复PP，不保存驱动参数；PV是否跨断电保留未验证。再次使用旧遥控前由其初始化设置PP模式，并核对回读。

日志每次独立保存于chassis_lift_control/logs/lift-pv-时间戳，含脚本快照、启动状态、joystick.jsonl、feedback.jsonl、events.jsonl、CAN收发can.jsonl、结束后文件哈希。CAN日志时间为用户态时间，非硬件时间。

离线验证：`python3 -m unittest discover -s reports/20260924_lift -p test_lift_pv_remote.py`。14项通过，不代表实机PV停车和重复启动已通过。只读和离线测试均不证明真实停止距离或负载保持能力。
