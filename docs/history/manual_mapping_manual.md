# 低速手动建图试验入口（2026-11-26）

NUC目录：`/home/pc/motion_mapping_trial_20261126`。此入口用于已校准相对候选的动态验证，非自主导航入口。车体锚点、地面残差与近场过滤仍未最终验收。

## 启动顺序

1. NUC与雷达通电，确认两台雷达无扫描模块错误；接好手柄，保持静止。
2. 一个终端开启只读原始时间监测：`sudo python3 /home/pc/motion_mapping_trial_20261126/raw_time_monitor.py --seconds 1800`。需要sudo因使用原始网卡接收；不用修改免密sudo规则。
3. 不与旧遥控、标定或建图程序同时启动。默认禁止运动的整链检查：`bash /home/pc/motion_mapping_trial_20261126/start_mapping.sh --seconds 30`。本命令控制器锁定，即使按START也不能使能。
4. 静止检查通过后，确认周围空地、急停可用、摇杆回中，进入低速试验：`bash /home/pc/motion_mapping_trial_20261126/start_mapping.sh --motion --seconds 900`。等待初始化约40秒，屏幕显示运动窗口开放后再按START。没有自动使能。最高平移0.05m/s、转向0.04rad/s；升降锁定。
5. 首次先短推前进约0.3–0.5米、回中停车，再缓慢转向或横移；不要一开始走长路线。按双扳机结束；Ctrl+C或试验目录STOP文件也可结束。

启动脚本会清除旧STOP标记，运行过程中创建STOP才代表此次停止请求。界面显示静止预检时保持静止。

## 保护及结果

原始时间监测要求四路数据持续有效，拒绝丢包、时间回跳、非PTP、内核丢包、主钟异常；通过后故障锁存，需要查明原因并重启监测，不能仅删除告警。遥控只接受同启动、同会话且250ms内刷新的许可，许可失效会退出并调用桥接器停车/失能清理；桥接器另有300ms输入超时。期限不是实测刹停时间。

`runs/时间/`保存配置、原始两台点云/IMU和融合点云录包、位姿、设备诊断、原始时间监测快照和遥控命令/轮速反馈。`accumulated_map.pcd`是每秒抽取配准扫描并按10cm体素去重的累计预览，不含回环，不是二维导航地图；完整数据留在bag。`last_scan_preview.pcd`只有末帧，不能当全图。

目前沿用逐雷达1m近场裁剪，仅用于开阔场地、人工观察下的低速算法试验。该范围内的障碍可能被滤掉，因此本入口不提供自动避障。录下原始点云后再核对裸底盘自反射范围并建立正式近场过滤，不能直接用本地图配置开放无人导航。

相对外参候选保持冻结；未修改厂家内参或原部署包入口，未开启自启。静止验证通过不代表动态精度验收。
